1. 访问部署后的公网地址

3. 进入系统后可查看：患者列表、健康指标、AI 咨询等功能

### 本地演示

#### 方式一：双击运行（推荐）

直接打开 `05_作品演示文件夹/public/index.html`，配置 `config.js` 中 `__DEMO_STATIC__ = true` 后即可使用全部演示功能。

#### 方式二：启动服务

```bash
cd 05_作品演示文件夹
npm start
```

浏览器访问 `http://localhost:3000`，使用本地账号 `admin` / `123` 登录。

#### 方式三：后端服务完整版

```bash
cd 03_作品代码文件夹/server
cp .env.example .env
npm install
npm start
```

浏览器访问 `http://localhost:3000`。

## 注意事项

- 演示账号仅包含模拟演示数据
- 评委如需查看完整功能，建议使用方式一（双击运行）或方式二（本地服务）
- 部署到公网时请务必更换密码
