# 社区慢病管理系统 · 作品总说明

> 2026 中国大学生计算机设计大赛 · 人工智能实践赛

## 作品简介

**社区慢病管理系统** 是一款面向社区慢性病患者的智能化健康管理平台。系统深度融合多智能体技术（Coze 平台）、微信小程序前端、Node.js 后端以及 SQLite 数据库，覆盖慢病患者日常监测、健康档案管理、AI 健康咨询、数据同步等全流程，实现"社区—医生—患者"三方联动的慢病闭环管理。

## 核心功能

| 功能模块 | 说明 |
|----------|------|
| 🏠 首页概览 | 患者信息展示、健康速览（血压/血糖/体重）、功能入口导航 |
| 📋 健康打卡 | 血压/血糖/体重记录、自动分级判定（正常/偏高/高） |
| 📁 我的档案 | 趋势图表（Canvas 绘制）、日/周/月切换、历史打卡记录 |
| 🤖 AI 健康咨询 | 智能对话界面、快捷健康问题、模拟 AI 回复（预留 Coze 对接） |
| 🔔 消息通知 | 随访提醒、用药提醒、健康周报、已读/未读管理 |
| 🔄 数据同步 | Coze 多智能体平台对接、手动/自动同步、同步日志 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端（演示） | HTML5 + CSS3 + Vanilla JavaScript |
| 前端（小程序） | 微信小程序原生开发（WXML + WXSS + JS） |
| 后端 | Node.js + Express |
| 数据库 | SQLite（better-sqlite3） |
| AI 平台 | Coze（扣子）多智能体平台 |
| 部署 | Vercel（含 Serverless API）/ GitHub Pages（纯静态） |

## 特色亮点

1. **多端覆盖**：微信小程序 + Web 端 + Coze 平台，三端数据互通
2. **AI 赋能**：接入 Coze 多智能体平台，实现智能健康咨询与数据分析
3. **适老化设计**：大字体、高对比度、简化操作流程
4. **数据闭环**：患者打卡 → 医生查看 → AI 建议 → 随访跟踪
5. **易部署易演示**：双击即开、Vercel 一键部署、演示视频录制零门槛
