# 提交前检查清单

## 需要填写到比赛系统的材料

- 作品主文件夹：`参赛提交材料/01_作品主文件夹`
- 作品代码文件夹：`参赛提交材料/03_作品代码文件夹`
- 作品文档文件夹：`参赛提交材料/04_作品文档文件夹`
- 作品演示文件夹：`参赛提交材料/05_作品演示文件夹`
- 评委演示账号：`参赛提交材料/评委演示账号.md`
- 部署与启动说明：`参赛提交材料/部署与启动说明.md`
- 安全说明：`参赛提交材料/安全说明.md`

## 压缩包

干净压缩包统一生成在根目录：

```text
待提交压缩包/
```

建议上传最新生成时间的压缩包，不再使用根目录旧压缩包。旧压缩包已备份到：

```text
本地私有_不要上传/旧压缩包_备份/
```

## 安全检查

- 不包含 `.env`
- 不包含真实 Coze/飞书/OpenClaw Token
- 不包含 `node_modules`
- 不包含运行数据库 `*.db`
- 公网 API 默认 `PUBLIC_API_READONLY=true`
