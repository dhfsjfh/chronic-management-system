# 社区慢病管理微信小程序

## 项目简介

本项目是一个面向社区慢病管理服务的微信小程序，目标用户是社区慢病患者（老年人为主）。小程序提供健康打卡、健康档案管理、AI健康咨询、消息通知等功能。

### 主要功能

- 🏠 **首页**：功能入口、轮播图、健康资讯
- 📝 **健康打卡**：血压、血糖、体重测量记录
- 📋 **我的档案**：健康档案概览、数据趋势图表
- 🤖 **AI咨询**：智能健康助手，支持语音输入
- 🔔 **消息通知**：随访提醒、系统公告、健康提醒

### 设计特点

- 👴 **老年人友好**：大字体、高对比度、简洁布局
- 📱 **响应式设计**：适配iOS和Android
- ⚡ **轻量高效**：主包控制在2M以内

## 快速开始

### 环境要求

- 微信开发者工具（最新版本）
- Node.js 14+（用于安装依赖）
- 微信小程序AppID

### 安装步骤

#### 1. 克隆项目

```bash
git clone <repository-url>
cd 社区慢病管理系统/miniprogram
```

#### 2. 安装Vant Weapp组件

项目使用 Vant Weapp 作为UI组件库，需要通过npm安装：

```bash
# 在项目目录下执行
npm init -y
npm install @vant/weapp -S --production
```

#### 3. 打开项目

1. 打开微信开发者工具
2. 点击"导入项目"
3. 选择项目目录
4. 填写AppID（使用测试号或自己的AppID）
5. 点击"确定"

#### 4. 构建npm

1. 在微信开发者工具中，点击"工具"菜单
2. 选择"构建npm"
3. 等待构建完成

#### 5. 开启调试

1. 点击"编译模式"旁的下拉箭头
2. 选择"普通编译"或"预览"
3. 确保"调试器"面板显示正常

## 页面说明

### 1. 首页 (pages/index)

入口页面，包含：
- 搜索栏
- 功能入口宫格
- 健康资讯轮播
- 今日打卡快捷入口
- 快捷操作入口

### 2. 健康打卡 (pages/checkin)

支持多种健康数据记录：
- **血压**：收缩压、舒张压、脉搏
- **血糖**：空腹血糖、餐后血糖
- **体重**：体重、身高（计算BMI）

特性：
- 数据合理性校验
- 历史记录查看
- 拍照识别（需对接OCR服务）

### 3. 我的档案 (pages/record)

三大Tab页面：
- **档案概览**：用户信息、疾病信息、责任医生
- **数据趋势**：折线图/柱状图展示
- **详细记录**：历史数据列表

### 4. AI咨询 (pages/ai)

智能健康助手：
- 文字输入咨询
- 语音转文字（需授权麦克风）
- 快捷问题推荐
- 推荐追问

### 5. 消息通知 (pages/msg)

消息分类：
- 随访提醒
- 系统公告
- 健康提醒

功能：
- 已读/未读状态管理
- 标记已读
- 清空消息

## 常见问题及解决方法

### 1. npm依赖安装失败

**问题**：npm install 报错

**解决方法**：
```bash
# 清除缓存后重新安装
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

### 2. 构建npm失败

**问题**：构建npm时报错

**解决方法**：
1. 确保微信开发者工具版本是最新的
2. 检查package.json是否正确
3. 删除miniprogram_npm后重新构建

### 3. 组件显示异常

**问题**：Vant组件样式异常

**解决方法**：
1. 确保已执行"构建npm"
2. 检查app.json中usingComponents配置
3. 清除缓存后重新编译

### 4. 页面样式错乱

**问题**：页面布局显示异常

**解决方法**：
1. 检查是否有样式覆盖
2. 确认CSS变量是否正确定义
3. 检查rpx单位使用是否正确

### 5. 登录功能异常

**问题**：Mock登录不生效

**解决方法**：
项目使用Mock数据进行演示，实际登录需要对接后端API。Mock数据定义在：
- `utils/auth.js` - login函数
- `utils/request.js` - requestLogin函数

## 真机调试注意事项

### 1. 授权问题

真机上需要用户手动授权：
- 用户信息授权
- 位置信息授权（用于推荐附近医院）
- 麦克风授权（用于语音输入）
- 相机授权（用于拍照识别）

确保在设置中开启相应权限。

### 2. 网络请求

- 真机调试时确保手机和小程序工具在同一网络环境下
- 如果使用本地接口，需要使用手机能够访问的IP地址
- 检查服务器域名配置是否正确

### 3. 样式适配

- 不同设备可能有细微差异
- 测试多种屏幕尺寸
- 检查安全区域适配

### 4. 性能问题

- 注意图片大小优化
- 避免在onLoad中执行过多同步操作
- 合理使用setData

## API对接说明

### 接口配置

在 `app.js` 中配置API基础地址：

```javascript
globalData: {
  apiBaseUrl: 'https://your-api-domain.com/api/v1',
  wsUrl: 'wss://your-api-domain.com/ws'
}
```

### 接口示例

#### 健康打卡

```
POST /health/checkin
{
  "type": "bloodPressure",
  "systolic": 120,
  "diastolic": 80,
  "pulse": 72
}
```

#### 获取健康档案

```
GET /health/profile
```

#### 发送AI咨询

```
POST /ai/chat
{
  "message": "高血压患者饮食注意什么？"
}
```

## 开发建议

### 代码规范

1. 变量命名清晰
2. 函数功能单一
3. 及时添加注释
4. 合理拆分文件

1. 避免频繁setData
2. 使用节流防抖
3. 图片懒加载
4. 合理使用分包

1. 字体不小于28rpx
2. 按钮高度不小于80rpx
3. 颜色对比度足够
4. 操作提示清晰
