# 慢病管理后端接手说明

## 当前目标

用 OpenClaw/Cursor 继续完善社区慢病管理系统后端，让微信小程序、Coze Bot、Coze 工作流、SQLite 数据库形成闭环。

## 已有模块

- 微信小程序首页：`miniprogram/`
- Node/Express 后端：`server/`
- SQLite 数据库：`server/data.db`
- OpenClaw 本机网关：`http://127.0.0.1:18789/`

## 后端启动

```bash
cd server
npm install
cp .env.example .env
npm start
```

服务默认地址：

```text
http://localhost:3000
```

## Coze 配置

后端已改成从环境变量读取 Coze 配置，不再把 PAT 写死在源码里。

必填：

```text
COZE_PAT_TOKEN=pat_xxx
COZE_WORKSPACE_ID=xxx
```

Bot 发布后填写：

```text
COZE_BOT_ID=xxx
```

Workflow 发布后填写：

```text
COZE_WORKFLOW_ID=xxx
```

状态检查：

```http
GET /api/ai/coze/status
```

## 核心 API

患者：

```http
GET /api/patients
GET /api/patients/:id
POST /api/patients
PUT /api/patients/:id
DELETE /api/patients/:id
```

生命体征：

```http
GET /api/blood-sugar?patient_id=1&days=7
POST /api/blood-sugar
GET /api/blood-pressure?patient_id=1&days=7
POST /api/blood-pressure
```

预警和回访：

```http
GET /api/alerts
POST /api/alerts/:id/process
GET /api/followups
POST /api/followups
POST /api/followups/:id/complete
```

AI 和 Coze：

```http
POST /api/ai/chat
POST /api/ai/agent
POST /api/ai/workflow/run
GET /api/ai/report/:patientId
```

## Cursor 下一步任务

1. 完成 Coze 已发布 Bot 对接：
   - 填写 `COZE_BOT_ID`
   - 校验 `/api/ai/chat` 和 `/api/ai/agent`
   - 把 Bot 返回内容落库到咨询记录表

2. 完成 Coze 工作流对接：
   - 填写 `COZE_WORKFLOW_ID`
   - 设计工作流入参：患者档案、血糖、血压、预警、回访历史
   - 返回健康建议、预警分级、随访任务

3. 打通数据闭环：
   - 新增 `ai_consultations` 表记录 AI 对话
   - 新增 `workflow_runs` 表记录工作流执行历史
   - AI 建议可生成 `alerts` 或 `followups`

4. 强化后端工程：
   - 增加 `.env` 加载，建议用 `dotenv`
   - 拆分路由：patients、vitals、alerts、followups、ai
   - 增加接口参数校验
   - 增加基础测试脚本

5. 前端联调：
   - 小程序 `miniprogram/utils/request.js` 的 `BASE_URL` 改为后端地址
   - 首页先联调：用户资料、资讯、打卡
   - 再联调：患者列表、报告、AI 咨询
