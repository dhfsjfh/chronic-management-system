# 部署与启动说明

## 一、本地启动（推荐——演示视频/现场展示）

### 方案 A：交互演示（最简，无需安装）

```bash
# 进入演示目录
cd 05_作品演示文件夹

# 编辑 public/js/config.js，设置：
# window.__DEMO_STATIC__ = true;

# 用浏览器直接打开 public/index.html 即可
open public/index.html
```

### 方案 B：Node.js 服务启动（需 Node.js 18+）

```bash
# 进入演示目录
cd 05_作品演示文件夹

# 启动服务（无需 npm install，使用内置 HTTP 模块）
node server.js

# 浏览器访问 http://localhost:3000
```

### 方案 C：完整后端启动

```bash
cd 03_作品代码文件夹/server

# 安装依赖
npm install

# 复制配置文件
cp .env.example .env

# 启动服务
npm start

# 浏览器访问 http://localhost:3000
```

## 二、公网部署（在线评审）

### Coze 公开演示（已生成）

```text
https://www.coze.cn/s/-LdnZbZJCI8/
```

该链接无需登录，可作为比赛后台的作品部署链接1。页面由 Coze 平台托管，访问范围受 Coze 分享与权限设置控制。建议另用手机流量和非登录浏览器各测试一次。

### Vercel 部署（推荐，含 Serverless API）

```bash
# 安装 Vercel CLI
npm install -g vercel

# 进入演示目录并部署
cd 05_作品演示文件夹
vercel --prod
```

部署后获得公网链接，可作为作品部署链接2或备用演示链接填入 `提交信息填写表.md`。

### GitHub Pages 部署（纯静态，无 API）

1. 上传 `05_作品演示文件夹/public/` 全部内容到 GitHub 仓库
2. 编辑 `js/config.js`，设置 `window.__DEMO_STATIC__ = true`
3. 仓库 Settings → Pages → 选择分支和 `/docs`（或根目录）
4. 获取 GitHub Pages 链接，填入 `提交信息填写表.md`

## 五、常见问题

**Q：登录后页面空白？**
A：检查 `config.js` 中 `__DEMO_STATIC__` 设置是否正确。本地文件打开需设为 `true`。

**Q：Node.js 服务启动失败？**
A：检查 Node.js 版本 ≥ 18。未安装则从 https://nodejs.org 下载。

**Q：如何切换中英文？**
A：当前系统使用中文界面。如需英文支持请在项目仓库中提交 Issue。
