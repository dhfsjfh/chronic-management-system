# 评委演示说明

## 1. 演示模式

后端支持 `DEMO_MODE=true`，用于评委只读体验。

- 环境变量：
  - `DEMO_MODE=true`
  - `JUDGE_ACCOUNT_PHONE=13800138001`
  - `JUDGE_ACCOUNT_PASSWORD=123`

## 2. 评委账号

- 手机号：`13800138001`
- 密码：`123`
- 角色：`judge`（只读）

## 3. 可体验范围

- 患者列表与患者档案
- 血压/血糖记录查看
- 预警列表查看
- AI 咨询与健康建议
- 健康报告查看

## 4. 禁止操作

- 删除患者
- 删除记录
- 关键配置修改
- 查看 `.env`、真实 token、本机路径等敏感信息

## 5. 关键接口

- `GET /api/demo/status`
- `POST /api/auth/login`
- `GET /api/patients`
- `GET /api/ai/report/:patientId`
- `POST /api/ai/chat`

危险写操作会返回：`演示模式下不可操作`。
