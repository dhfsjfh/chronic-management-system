================================================
  社区慢病管理系统 - 极简运行说明
================================================

【启动方式】
  方式一：双击 index.html（最简，无需服务端）
  方式二：python3 -m http.server 8080
          → 浏览器访问 http://localhost:8080

【默认账号】
  用户名：admin
  密  码：123

【核心功能列表】
  1. 首页概览 - 患者信息 + 健康速览
  2. 健康打卡 - 血压/血糖/体重 + 自动分级
  3. 我的档案 - 趋势图表 + 历史记录
  4. AI咨询  - 智能对话 + 快捷提问
  5. 消息通知 - 随访/用药/周报提醒
  6. 数据同步 - Coze平台对接（预留）

【浏览器要求】
  Chrome / Edge / Firefox 最新版

【提交说明】
  本目录可直接打包为 zip，提交至 OpenClaw 平台
