## 二、本地联调部署（用于答辩现场备用）

### 1) 启动后端

```bash
cd server
npm install
cp .env.example .env
npm start
```

默认地址：`http://127.0.0.1:3000`

### 2) 小程序联调

将 `miniprogram/utils/request.js` 中的 `BASE_URL` 设置为：

```text
http://127.0.0.1:3000
```

### 3) 医生端演示页

直接打开：`coze-page-export/index_v2.html`

## 三、部署前检查清单

- [ ] 删除或不提交 `server/.env`
- [ ] 不提交真实 PAT token
- [ ] 不提交 `node_modules/`
- [ ] 不提交 `*.db`、`*.db-wal`、`*.db-shm`
- [ ] 演示账号密码已统一为 `123`
